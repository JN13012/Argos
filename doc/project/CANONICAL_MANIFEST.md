## IMPLEMENTATION NOTES

[Discovery V0](../livrables/DISCOVERY_V0.md) conserve le contrat de la première
implémentation OSINT Discovery. Le [guide du front](../interface/FRONTEND.md)
et les [guides d'utilisation](../README.md#guides) décrivent les prototypes
existants. Ils ne déclarent pas la cible entièrement implémentée.

Les contrats existants restent inchangés. Les instructions opérationnelles de
[AGENTS.md](../../AGENTS.md) restent applicables au lot hors ligne ; la vision
nouvelle ne vaut pas autorisation d'implémenter toute l'architecture.
